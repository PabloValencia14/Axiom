# Política de seguridad

No publiques vulnerabilidades, tokens, claves, libros, bases de datos, registros ni capturas con datos personales en incidencias o pull requests.

Usa **Report a vulnerability** en la pestaña Security de GitHub para enviar un aviso privado. Si la opción no está disponible, contacta al mantenedor mediante el correo de seguridad publicado en su perfil de GitHub; describe el componente, impacto y pasos mínimos de reproducción, sin incluir datos de otras personas. No existe un SLA de respuesta garantizado.

No incluyas secretos reales en reportes. Si una credencial tuya quedó expuesta, revócala primero con su proveedor.
